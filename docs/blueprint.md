# **App Name**: MySuCasa AI Finder

## Core Features:

- Property Search: Allow users to search for properties based on various criteria like location, price, and size.
- AI-Powered Recommendations: Utilize AI algorithms to analyze user preferences and suggest suitable properties.
- Property Details Display: Display detailed information about each property, including photos, descriptions, and features.
- Neighborhood Insights: Provide insights into the neighborhood surrounding each property, including schools, amenities, and safety ratings, with the help of a tool.
- User Account Management: Allow users to create and manage their accounts to save favorite properties and search criteria.

## Style Guidelines:

- Primary color: Light desaturated blue (#ADD8E6) to evoke a sense of trust and reliability, which is important for real estate.
- Background color: Very light desaturated blue (#F0F8FF), almost white, to provide a clean and calm backdrop.
- Accent color: Muted teal (#70A1AF) to highlight key actions and elements without being overwhelming.
- Headline font: 'Playfair', serif, for an elegant, high-end feel, best for headlines.
- Body font: 'PT Sans', sans-serif, is paired with Playfair, and offers readability for longer text.
- Use simple, clear icons to represent property types and features.
- Prioritize clean, intuitive layouts with ample white space to make property listings easy to scan.
